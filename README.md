# Telegram-Anonymous-Bot
A Telegram bot that allows users to send **messages, photos, videos, files, stickers, and more** to each other **anonymously**.   Each user is assigned a random nickname (e.g., `User1001`), so identities stay hidden.

1. Clone this repo:
2. bash
   git clone https://github.com/yourusername/telegram-anon-bot.git
   cd telegram-anon-bot
Install dependencies:

bash
Copy code

Get a bot token from BotFather on Telegram.

Open main.py and replace:

python
